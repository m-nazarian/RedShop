# مرحله چهلم: افزودن گارد ساختار تست‌ها

در این مرحله یک تست گارد برای ساختار تست‌های orders اضافه شد.

## تغییرات

- فایل `apps/orders/tests/test_test_structure.py` اضافه شد.
- تست جدید بررسی می‌کند که فایل‌های تست دیگر از `test_checkout_payment.py` به‌عنوان محل helper مشترک import نکنند.
- وابستگی مجاز به helper مشترک باید از `apps.orders.tests.helpers` باشد.

## نتیجه

اگر در آینده دوباره فایل‌های تست به `test_checkout_payment.py` وابسته شوند، تست‌ها خطا می‌دهند و ساختار تمیز فعلی حفظ می‌شود.
