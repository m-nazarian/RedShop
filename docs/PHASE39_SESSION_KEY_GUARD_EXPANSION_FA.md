# مرحله سی‌ونهم: گسترش گارد session key

در این مرحله گارد session key با ساختار جدید پکیج تست‌ها هماهنگ شد.

## تغییرات

- گارد session key به‌جای بررسی چند فایل تست ثابت، کل فایل‌های Python داخل `apps/orders/tests` را بررسی می‌کند.
- فایل `helpers.py` هم زیر پوشش گارد قرار گرفت.
- ارجاع ثابت به `test_checkout_payment.py` حذف شد.

## نتیجه

با اضافه‌شدن یا جابه‌جایی فایل‌های تست داخل پکیج orders، گارد session key همچنان همه فایل‌های تست را بررسی می‌کند.
