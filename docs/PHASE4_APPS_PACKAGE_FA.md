# مرحله چهارم: انتقال اپ‌ها به پکیج apps

در این مرحله اپلیکیشن‌های داخلی Django از ریشه پروژه به پکیج pps/ منتقل شدند.

## ساختار جدید

- pps/account
- pps/cart
- pps/compare
- pps/coupons
- pps/orders
- pps/payment
- pps/shop

## نکته مهم Django

مقدار AppConfig.name مسیر کامل پایتونی اپ است، اما label همان نام قبلی اپ نگه داشته شده تا migrationها، جدول‌های دیتابیس و مقدار AUTH_USER_MODEL تغییر نکنند.

## فایل‌های تمیزشده

فایل‌های موقت اجرای Patch، خروجی بررسی پروژه، کش‌های پایتون و فایل‌های اضافی ریشه پروژه حذف یا از Git خارج شدند.
