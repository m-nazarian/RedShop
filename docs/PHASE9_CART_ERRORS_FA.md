# مرحله نهم: استانداردسازی خطاهای Cart

در این مرحله Viewer مربوط به Cart استانداردتر شدند.

## تغییرات

- `except:` عمومی از `update_quantity` و `remove_item` حذف شد.
- خطاهای قابل پیش‌بینی با پاسخ JSON فارسی و status code مناسب برمی‌گردند.
- عملیات نامعتبر، محصول خارج از سبد، شناسه خالی و تعداد بیشتر از موجودی جداگانه مدیریت می‌شوند.
- Payload موفقیت در یک تابع کمکی مشترک ساخته می‌شود.
- دریافت Product با QuerySet بهینه و `get_object_or_404` انجام می‌شود.
- تست‌های AJAX برای مسیرهای خطا و موفقیت اضافه شد.

## نتیجه

کد Cart قابل‌پیش‌بینی‌تر، قابل تست‌تر و نزدیک‌تر به الگوی استاندارد Django/Python شد.
