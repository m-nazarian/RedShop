# مرحله بیست‌ونهم: افزودن Dependabot

در این مرحله برای نگه‌داری dependencyها و workflowهای GitHub Actions فایل Dependabot اضافه شد.

## تغییرات

- فایل `.github/dependabot.yml` اضافه شد.
- آپدیت هفتگی GitHub Actions فعال شد.
- آپدیت هفتگی dependencyهای Python/pip فعال شد.
- برای pull requestهای Dependabot برچسب‌های `dependencies`، `github-actions` و `python` تنظیم شد.

## نتیجه

بعد از این مرحله، GitHub می‌تواند برای dependencyها و actionهای قدیمی pull request بسازد تا نگه‌داری پروژه ساده‌تر شود.
