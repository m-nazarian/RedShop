# مرحله بیست‌وپنجم: تمیزکاری فاصله‌ها

بعد از چند refactor پشت‌سرهم، چند فاصله اضافه یا کم‌شده در فایل‌های تست، پرداخت و session keyها مرتب شد.

## تغییرات

- فاصله بین تست‌های تازه اضافه‌شده مرتب شد.
- فاصله قبل از helperهای top-level در `session_keys.py` استانداردتر شد.
- فاصله قبل از `payment_process` در `payment/views.py` مرتب شد.

## نتیجه

این مرحله فقط خوانایی و نظم فایل‌ها را بهتر می‌کند و رفتار برنامه را تغییر نمی‌دهد.
