# مرحله هشتم: بهینه‌سازی Queryها

در این مرحله چند مسیر پرتکرار با `select_related` و `prefetch_related` بهینه شدند.

## تغییرات اصلی

- محصولات در لیست و فیلترها همراه با `category` و `brand` خوانده می‌شوند.
- تصاویر و رنگ‌های محصولات با `prefetch_related` آماده می‌شوند.
- صفحه جزئیات محصول، ویژگی‌ها، تصاویر، رنگ‌ها، نظرات و محصولات مرتبط را بهینه‌تر می‌خواند.
- پارشیال علاقه‌مندی‌ها و نظرات کاربر روابط محصول را آماده‌تر می‌کند.
- لیست سفارش‌ها و جزئیات سفارش آیتم‌ها را از قبل می‌خوانند.
- Cart view هنگام دریافت محصول، روابط اصلی محصول را آماده‌تر می‌کند.

## هدف

این تغییرات رفتار کاربر را عوض نمی‌کند، اما تعداد Queryهای تکراری در رندر صفحات را کمتر می‌کند و پایه مناسبی برای تست‌های کارایی بعدی می‌سازد.
