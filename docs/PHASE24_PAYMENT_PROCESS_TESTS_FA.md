# مرحله بیست‌وچهارم: تست مستقیم payment_process

بعد از کوچک‌کردن `payment_process`، دو تست مستقیم برای شاخه‌های حساس آن اضافه شد.

## تغییرات

- تست سفارش online از قبل پرداخت‌شده اضافه شد.
- تست سفارش online با `stock_released=True` اضافه شد.
- هر دو تست پاک‌شدن `order_id` و `checkout_order_id` را بررسی می‌کنند.

## نتیجه

refactor مرحله قبل پوشش تستی مستقیم‌تری برای مسیرهای ابتدایی پرداخت دارد.
