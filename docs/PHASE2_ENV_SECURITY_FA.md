# مرحله دوم: جداسازی تنظیمات حساس

در این مرحله تنظیمات حساس از `settings.py` خارج شد و از `.env` خوانده می‌شود.

## فایل‌های اصلی

- `RedShop/env.py`: خواندن مقدارها از محیط و فایل `.env`
- `.env`: تنظیمات محلی و محرمانه، خارج از گیت
- `.env.example`: نمونه بدون مقدار محرمانه برای مستندسازی
- `RedShop/settings.py`: استفاده از متغیرهای محیطی برای Secret، دیتابیس، ایمیل و زرین‌پال

## نکته امنیتی

رمزهایی که قبلاً داخل سورس بوده‌اند باید تعویض شوند. انتقال آن‌ها به `.env` جلوی تکرار افشا را می‌گیرد، اما افشای قبلی را خنثی نمی‌کند.

## وضعیت توسعه محلی

فعلاً تنظیمات امنیتی سخت‌گیرانه مثل HTTPS Redirect و HSTS خاموش مانده‌اند تا اجرای محلی پروژه در PyCharm بدون مشکل ادامه پیدا کند.
