# مرحله چهل‌وسوم: تقویت گارد helper مشترک تست‌ها

در این مرحله گارد ساختار تست‌ها برای helper مشترک orders دقیق‌تر شد.

## تغییرات

- یک تست جدید به `apps/orders/tests/test_test_structure.py` اضافه شد.
- تست جدید بررسی می‌کند که `RedShopTestBase` داخل فایل‌های `test_*.py` دوباره تعریف نشده باشد.
- تست جدید بررسی می‌کند که import مربوط به `RedShopTestBase` فقط از `apps.orders.tests.helpers` انجام شود.

## نتیجه

ساختار helper مشترک تست‌ها پایدارتر شد و اگر در آینده helper دوباره به فایل‌های تست برگردد، تست‌ها خطا می‌دهند.
