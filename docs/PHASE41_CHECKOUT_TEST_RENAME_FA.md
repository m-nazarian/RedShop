# مرحله چهل‌ویکم: تغییر نام فایل تست checkout

در این مرحله فایل تست اصلی checkout بعد از جداسازی تست‌های payment، cart، profile و shop به نام دقیق‌تری تغییر کرد.

## تغییرات

- فایل `apps/orders/tests/test_checkout_payment.py` به `apps/orders/tests/test_checkout_flow.py` تغییر نام داد.
- گارد ساختار تست‌ها ساده‌تر شد و دیگر فایل قدیمی را استثنا نمی‌کند.

## نتیجه

نام فایل تست با محتوای فعلی آن هماهنگ‌تر شد و ساختار تست‌ها شفاف‌تر باقی ماند.
